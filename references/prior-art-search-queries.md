# Prior-art search query guide

Generate search queries from the user's disclosure.

## Chinese query patterns

- "[核心材料/结构] [功能/效果] [应用场景] 专利"
- "[核心方法] [技术问题] 发明专利"
- "[材料A] [材料B] [制备方法] [性能指标]"
- "[装置模块1] [装置模块2] [连接关系/控制方法]"
- "[算法/模型] [传感器/硬件] [技术效果]"

## English query patterns

- "[core material/device/method] [function] [application] patent"
- "[technical problem] [solution mechanism] invention"
- "[composition] [preparation method] [performance metric]"
- "[algorithm/model] [hardware/sensor] [technical effect]"

## Database checklist

- CNIPA patent search or public patent announcement resources
- WIPO Patentscope
- Espacenet
- Google Patents
- Lens
- Scholar databases and publishers appropriate to the field
- Standards or regulatory sources if the invention depends on compliance

## Search record minimum

For each material prior-art item, record title, publication number or DOI if available, date/year, applicant/author, key overlapping features, key differences, and citation link.
